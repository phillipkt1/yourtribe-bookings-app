# YourTribe Bookings

A room-booking web app designed for one iPad. Bookings are stored in that iPad's browser storage and are not shared across devices.

## Publish with GitHub Pages
1. Open the repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Choose branch `main`, folder `/ (root)`, then **Save**.
4. Wait for the Pages deployment. The site URL will appear on the Pages settings screen.

## Add to the iPad Home Screen
Open the published URL in Safari, tap **Share → Add to Home Screen**, then tap **Add**.
